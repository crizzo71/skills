# Codex Skills

Personal Codex skills for reusable workflows.

## Skills

- [`hypershell-monthly-github-report`](hypershell-monthly-github-report/README.md): Generate a monthly GitHub development report for `openshift-online/hypershell`, with optional secret Gist publishing.

## Install

Clone this repository and copy or symlink the desired skill folder into `~/.codex/skills/`.

Example:

```bash
git clone https://github.com/crizzo71/skills.git
cp -R skills/hypershell-monthly-github-report ~/.codex/skills/
```
